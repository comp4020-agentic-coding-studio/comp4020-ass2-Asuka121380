<WeekBand index={2} label="Standing waves" heading="Nodes, antinodes, and the fundamental" layout="wide">

<StandingWaveDiagram />

A string fixed at both ends can only vibrate in a limited set of shapes —
**standing waves** — each with fixed points (**nodes**) that never move and
points of maximum motion (**antinodes**) between them. The lowest of these,
the **fundamental**, sets the pitch you hear; the higher modes are its
**harmonics**. For an idealised string, fₙ = n·f₁ — each harmonic sits at an
exact whole-number multiple of the fundamental. Real strings aren't perfectly
ideal, so this relationship holds closely but not exactly.

The fundamental itself follows f₁ = 1/(2L) · √(T/μ), where L is the vibrating
length, T is tension, and μ is the string's mass per unit length. Shortening
the string, tightening it, or using a lighter string all raise the
fundamental. Fretting a string is exactly a length change — the twelfth fret
halves the vibrating length, which (holding tension and mass per length
fixed) doubles the fundamental frequency: an octave up.

</WeekBand>

<WeekBand index={3} label="Before electronics" heading="Picking position: an early kind of tone shaping">

Where a string is plucked doesn't change *which* frequencies are available —
those are set by length and tension — but it changes how strongly each mode
gets excited. Picking near the middle of the string favours the fundamental
and suppresses harmonics that have a node there; picking close to the bridge
excites a richer set of higher harmonics. This is an early example of
spectral tone shaping that happens before any electronics are involved at
all. The spectrum also isn't static after the pluck — it keeps evolving
through the note's attack and decay, a detail this week only flags rather
than develops.

</WeekBand>
