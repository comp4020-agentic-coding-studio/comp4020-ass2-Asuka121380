## Slides are markdown

A `---` starts a new slide. Everything else is ordinary markdown: headings,
lists, links, tables, images, fenced code.

- one idea per slide
- the fewest words that carry it
- the deck is a performance artefact, so it can say things a page wouldn't

# A slide class

`{/* _class: impact */}` fills the slide with the brand colour. `quote`,

## What else is here

```sh
pnpm dev
pnpm check
```

The second command proves the deck compiles with the rest of the site. Use the
first to inspect every slide at the desktop and phone marking viewports; slide
fit and legibility are visual judgements.

The [astromotion](https://github.com/ANUcybernetics/astromotion) README has the
rest of the syntax: speaker notes, backgrounds, QR codes, fragments, and
components hydrated per slide.
